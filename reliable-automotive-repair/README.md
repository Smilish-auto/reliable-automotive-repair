# Reliable Automotive Repair Website

Responsive static website concept for Reliable Automotive Repair, Akobo, Ibadan.

## Edit business details
Open `script.js` and update the `business` object. Phone, WhatsApp, address and Maps links are centralized there.

## Run locally
Open `index.html` in a browser. For best results, use VS Code + Live Server.

## Deploy
Upload the folder to GitHub and import the repository into Vercel or Netlify.

## Before client launch
Confirm actual services, workshop photos, testimonials, exact map pin, business hours, and all claims with the owner.
